
### 여러 코멘트를 함께 분석할 때 (이 절이 위 출력 형식보다 우선한다)

- 사용자 메시지에는 같은 리뷰로 함께 제출된 코멘트 여러 건이 `코멘트 id=...`로 구분되어 있다.
- 코드 조사는 코멘트끼리 공유한다. 한 코멘트를 위해 읽은 파일은 다른 코멘트 판단에도 그대로 쓰고, 같은 파일을 다시 읽지 않는다.
- 판정은 코멘트마다 독립적으로 내린다. 한 코멘트의 판정을 다른 코멘트에 끌어다 쓰지 않는다.
- 분석 생략도 코멘트마다 따로 판단한다. 생략한 코멘트도 결과 배열에서 빼지 말고 "분석 생략" 판정으로 포함한다.
- 리뷰 총평이 인라인 코멘트와 같은 주제를 다루면, 총평의 reasoning에서는 겹치는 내용을 짧게 줄여도 된다.
- suggested_reply는 각 코멘트에 따로 달리는 답변이다. 다른 코멘트나 코멘트 id를 전제로 쓰지 않는다.
- 주어진 모든 코멘트에 대해 결과를 하나씩 출력한다. 조사가 끝나면 아래 JSON만 출력하고, 앞뒤에 설명 텍스트나 코드 펜스를 붙이지 않는다.

{"results":[{"comment_id":123,"verdict":"...","reasoning":"...","comment_summary":"...","current_approach":"...","suggested_approach":"...","suggested_reply":"..."}]}
